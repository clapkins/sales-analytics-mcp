# Скриншоты работы системы

Сюда кладутся скриншоты диалога с LLM-клиентом (Claude Desktop) —
демонстрационный материал, который требует ТЗ («скриншоты или видео
работы чат-интерфейса с примером диалога»).

Что стоит заснять:

1. **Список инструментов** — окно клиента, где видно, что сервер
   `sales-analytics` подключён и отдаёт инструменты (`load_data`,
   `describe_data`, `plot_trend`, `plot_distribution`,
   `correlation_analysis` и остальные).
2. **Вызов `load_data`** — запрос пользователя и ответ модели со
   сводкой по структуре данных.
3. **Очистка** — вызов `clean_data` с логом операций (сколько дублей
   удалено, пропусков заполнено, выбросов найдено).
4. **Построение графиков** — один-два вызова `plot_*` с описанием
   графика в ответе.
5. **Итоговый отчёт** — текст с выводами и рекомендациями, который
   модель написала сама (см. `reports/sample_report.md`).

Имена файлов — по порядку шагов, например `01_tools.png`,
`02_load_data.png` и так далее, чтобы README читался сверху вниз.
